# Planteamiento del Problema

## 1. Problema

Actualmente, las personas que quieren aprender o conocer más sobre la trompeta deben buscar información en diferentes páginas, videos y documentos. Esto puede dificultar el aprendizaje, especialmente para quienes están comenzando a estudiar este instrumento.

## 2. Causas

- La información sobre la trompeta está distribuida en diferentes sitios.
- Existen pocos sitios que reúnan información y ejercicios en un solo lugar.
- Los principiantes pueden tener dificultades para encontrar contenido organizado.
- No siempre es fácil encontrar recursos adecuados para comenzar a aprender.

## 3. Consecuencias

- Se pierde tiempo buscando información.
- Los estudiantes pueden encontrar contenido desorganizado.
- Puede ser más difícil iniciar el aprendizaje del instrumento.
- Se dificulta encontrar en un solo lugar recursos para estudiar y practicar.

## 4. Aporte

El proyecto consiste en desarrollar un sitio web educativo sobre la trompeta que reúna información sobre su historia, partes, evolución, técnicas y ejercicios. El sitio tendrá una estructura sencilla y será Responsive, permitiendo acceder a la información desde computadores, tablets y celulares.

## 5. Objetivo

Crear un sitio web que facilite el acceso a información y recursos básicos sobre la trompeta, sirviendo como apoyo para estudiantes y personas interesadas en aprender sobre este instrumento.




# Épicas e Historias de Usuario

## 1. Épica: Información sobre la trompeta

**Como usuario**, quiero consultar información sobre la trompeta para conocer mejor el instrumento.

### Historias de usuario

- **1.1.** Como usuario, quiero conocer la historia de la trompeta para aprender sobre su origen y evolución.
- **1.2.** Como usuario, quiero conocer las partes de la trompeta para identificar sus componentes.
- **1.3.** Como usuario, quiero conocer los diferentes tipos de trompeta para saber cuáles existen.
- **1.4.** Como usuario, quiero conocer la importancia de la trompeta en diferentes géneros musicales.

## 2. Épica: Aprendizaje y práctica

**Como estudiante**, quiero encontrar información y ejercicios que me ayuden a mejorar mi forma de tocar la trompeta.

### Historias de usuario

- **2.1.** Como estudiante, quiero consultar ejercicios básicos para mejorar mi técnica.
- **2.2.** Como estudiante, quiero conocer las escalas musicales para practicar.
- **2.3.** Como estudiante, quiero conocer técnicas de respiración para mejorar mi interpretación.
- **2.4.** Como estudiante, quiero consultar recomendaciones para realizar una buena práctica.

## 3. Épica: Usuarios

**Como usuario**, quiero crear una cuenta para acceder a las funciones disponibles en el sitio web.

### Historias de usuario

- **3.1.** Como usuario, quiero registrarme en el sitio web para crear una cuenta.
- **3.2.** Como usuario, quiero iniciar sesión para acceder a mi cuenta.
- **3.3.** Como usuario, quiero cerrar sesión para proteger mi cuenta.

## 4. Épica: Gestión del contenido

**Como administrador**, quiero gestionar el contenido del sitio web para mantener actualizada la información.

### Historias de usuario

- **4.1.** Como administrador, quiero agregar contenido para mantener actualizada la página.
- **4.2.** Como administrador, quiero modificar contenido para corregir o actualizar información.
- **4.3.** Como administrador, quiero eliminar contenido que ya no sea necesario.
- **4.4.** Como administrador, quiero consultar los usuarios registrados para administrar el sistema.

## 5. Épica: Interacción con el sitio

**Como usuario**, quiero interactuar con el contenido para compartir mi opinión y resolver dudas.

### Historias de usuario

- **5.1.** Como usuario, quiero dejar comentarios sobre el contenido.
- **5.2.** Como usuario, quiero consultar los comentarios de otros usuarios.
- **5.3.** Como usuario, quiero navegar fácilmente entre las diferentes secciones del sitio.
